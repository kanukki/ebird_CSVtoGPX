eBird Hotspots → GPX

Convert an eBird hotspot CSV into a GPX waypoint file for Gaia GPS. Runs entirely in your browser — nothing is uploaded anywhere.

  1. Get your API key once from ebird.org/api/keygen.
  2. Paste this into your browser address bar, with your region code and key filled in:
    https://api.ebird.org/v2/ref/hotspot/REGIONCODE?fmt=csv&key=YOURKEY
  3. Save the downloaded CSV, then drop it below.
