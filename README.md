Create an eBird API Key from https://ebird.org/api/keygen
Identify the REGIONCODE by explore regions. The region code will appear in the URL, such as: https://ebird.org/region/PT-08-TA (for Tavira, Portugal)
Access the URL, replacing the values for REGIONCODE and YOURKEY: https://api.ebird.org/v2/ref/hotspot/REGIONCODE?fmt=csv&key=YOURKEY
Upload the generated CSV to this converter
